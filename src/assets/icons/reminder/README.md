# Reminder icon family

Approved on 2026-10-10. Seven transparent 256 × 256 PNGs share filled shapes,
subtle gradients, and blue / teal / amber / violet category colors. Application
controls use the separate `AppIcon.vue` stroke icon component.

Generated with `gpt-image-2`, using the existing application mark as a color
reference. The provider returned a 1774 × 887 sheet for a 2048 × 1024 request.
The original was preserved; each icon was extracted and downsampled without
upscaling. Production uses these local assets and needs no image service.

The original, exact prompt, extraction script, and manifest are retained in the
local design archive `outputs/audit-2026-10-10/icons-v2/`.
